# ✨ Vibes Programming Language (VPL)

**VPL** is a chaotic, LLM‑powered meme programming language.  
You write `.vibe` files full of pure vibes, and the compiler turns them into real Python code using Gemini.

VPL is not deterministic.  
VPL is not safe.  
VPL is not stable.  
But VPL has **vibes**.

---

## 🚀 Features

- Custom file extension: `.vibe`
- LLM‑based compiler using Gemini
- Automatic API key detection
- Interactive API key prompt on first run
- Persistent key storage in `~/.vibes_api_key`
- Generates executable Python code (`out.py`)
- Minimal, fun, chaotic
